# LingoMic

Live voice translation, captions and AI meeting notes for Google Meet, Zoom and Microsoft Teams.

- Website: https://lingomic.com
- Windows app: [Releases](https://github.com/kaokray/LingoMic/releases) (the app updates itself from here)
- Chrome extension: Chrome Web Store

`config.json` holds the names of the Gemini models the extension uses; it is read every few hours
from https://kaokray.github.io/LingoMic/config.json. No user data is sent with that request.
